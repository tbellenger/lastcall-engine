# lastcall-engine

A Sierra-style adventure engine. The rules, parser, pathfinding, and software renderer live in a deterministic Rust core. The same package plays in a browser (WebAssembly), in a native desktop window, and under a headless script runner.

Licence: MIT OR Apache-2.0. See `LICENSE-MIT` and `LICENSE-APACHE`.

## Layout

| Path | Role |
| --- | --- |
| `crates/core` | Engine. No clock, filesystem, or browser APIs |
| `crates/advc` | `validate`, `pack`, and `test` for an authoring folder |
| `crates/wasm` | wasm-bindgen exports used by the browser shell |
| `crates/advplay` | Native player (`winit` + `softbuffer`, `rodio` for a short beep) |
| `web` | Vite + TypeScript shell |
| `fixtures/sample` | Original two-room game, The Gatehouse |
| `schemas` | JSON Schemas for the authoring files and the package manifest |
| `docs/format-v0.md` | Package format v0 |

Pictures are a fixed 384×216. The host upscales that framebuffer with integer nearest-neighbour filtering and letterboxing.

## Build and test

Stable Rust, with `rustfmt`, `clippy`, and the `wasm32-unknown-unknown` target (see `rust-toolchain.toml`).

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo run -p advc -- validate fixtures/sample
cargo run -p advc -- test fixtures/sample
```

`advc test --update-snapshots` rewrites `fixtures/sample/tests/boot.sha256` and the `.sha256` / `.png` files under `fixtures/sample/tests/snapshots/`. CI fails when those drift.

Pack a folder into a `.advpak`:

```bash
cargo run -p advc -- pack fixtures/sample -o game.advpak
```

### Browser

```bash
cargo install wasm-bindgen-cli --version 0.2.100 --locked
bash scripts/build-wasm.sh
cargo run -p advc -- pack fixtures/sample -o web/public/sample.advpak
cd web
npm ci
npm run typecheck
npm run build
npm run dev
```

Arrow keys walk. Type into the page and press Enter; Enter also dismisses narration. The canvas is 384×216 and scaled by an integer factor. Narration is mirrored in an ARIA live region. Save slots and the autosave go to IndexedDB (`lastcall`). The first pointer or key unlocks a short Web Audio beep when the core emits a sound effect.

`npm run test:e2e` checks that the boot framebuffer hash matches `fixtures/sample/tests/boot.sha256`.

### Desktop

```bash
cargo run -p advplay -- path/to/game.advpak
cargo run -p advplay -- --dump-frame path/to/game.advpak
```

With no path, a bundled `sample.advpak` (inside a macOS app) is loaded. Otherwise a file chooser opens. Arrow keys walk, typed characters fill the command line, Enter submits or dismisses, Escape dismisses, F5 saves slot 1, and F7 restores it. Saves are written under `~/.lastcall/saves/<package-name>/`.

`--dump-frame` prints the boot framebuffer SHA-256 and does not open a window. `--expect <file>` exits non-zero when the hash differs.

On Linux the binary links GTK 3 (file chooser), X11 or Wayland, libxkbcommon, and ALSA:

```bash
sudo apt install libgtk-3-dev libasound2-dev libxkbcommon-dev libwayland-dev libx11-dev pkg-config
```

Runtime packages are `libgtk-3-0`, `libx11-6`, `libxkbcommon0`, and `libasound2` (or `libasound2t64`).

## Sample game

The Gatehouse is a two-room game: a porch with a brass key, a locked door, a stone well, and a pillar you can walk behind, then a yard. Score 10. Climbing into the well is fatal and restores the checkpoint taken as the game starts.

```text
look at the rim
get key
unlock door
```

Headless coverage is `fixtures/sample/tests/golden.walk` and `death.walk`. Placeholder art is generated by `fixtures/sample/gen_art.py`.

## Download a desktop build

CI uploads two artifacts on every push to `main` and every pull request.

| Artifact | What you get after unzipping |
| --- | --- |
| `lastcall-advplay-macos-universal` | `LastCall.app` (universal binary) and `README.txt` |
| `lastcall-advplay-linux-x86_64` | `advplay`, `sample.advpak`, and `README.txt` |

A `v*` tag also attaches `LastCall-macos-universal.zip` and `LastCall-linux-x86_64.tar.gz` to the GitHub Release. The builds are unsigned.

### macOS

1. Open the Actions tab and the latest successful CI run on `main`.
2. Download the artifact **`lastcall-advplay-macos-universal`**.
3. Unzip it. You should see `LastCall.app` and `README.txt`.
4. The app is unsigned, so Gatekeeper quarantines it. Right-click `LastCall.app` and choose Open, or clear the flag from Terminal (use `-dr` so nested files inside the bundle are cleared too; `xattr -d` only clears the one path you name):

```bash
xattr -dr com.apple.quarantine LastCall.app
```

5. Double-click `LastCall.app`. It loads the bundled sample, The Gatehouse.
6. To open another package:

```bash
LastCall.app/Contents/MacOS/advplay /path/to/game.advpak
```

From a Release, download `LastCall-macos-universal.zip` instead of the Actions artifact. It contains the same app and readme.

### Linux x86_64

Download **`lastcall-advplay-linux-x86_64`** (or `LastCall-linux-x86_64.tar.gz` from a Release), install the libraries noted above, and run:

```bash
./advplay sample.advpak
```

## Later

Phase 1 stops at the core, the packer, the sample, the browser shell, and the desktop player. Porting Charlie on top of this needs script hooks, move timers, named checkpoint restores, actor state machines, cutscene timelines, and an importer, then parity against frozen transcripts. The rules, parser, saves, priority renderer, walk tests, wasm host, and desktop player are already here, so that work is data and scripts on top of this engine rather than a new one.
